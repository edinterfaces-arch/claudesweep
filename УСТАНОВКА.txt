CLAUDE SWEEP — КАК УСТАНОВИТЬ И ЗАПУСТИТЬ

Сначала прочитайте это
---------------------
Программа предназначена для Mac с macOS 13 или новее.
На Windows, iPhone и Android этот архив не запускается.
Версию macOS можно посмотреть: меню Apple  → «Об этом Mac».

В архиве находится исходный код, а не готовая программа.
Сценарий ниже должен собрать приложение и создать установочный файл DMG
на вашем Mac. Знать программирование для этих шагов не нужно.
Это предварительная версия: сборка, 14 тестов и пробный запуск на Mac
проверены. Реальная очистка и удаление записей Keychain ещё не проверены.
Если возникнет ошибка, сохраните её текст — инструкция ниже объясняет как.

ШАГ 1. РАСПАКУЙТЕ АРХИВ
-----------------------
1. Скачайте ClaudeSweep-macOS-source.zip.
2. Откройте Finder → «Загрузки» и дважды нажмите на архив.
3. Откройте появившуюся папку ClaudeSweep.
   В ней должны быть файлы Build.command и Package-DMG.command.
   Не переносите эти файлы отдельно от остальных файлов папки.

ШАГ 2. УСТАНОВИТЕ ИНСТРУМЕНТЫ APPLE
---------------------------------
Это нужно один раз для сборки приложения. Требуются инструменты
Command Line Tools с языком Swift версии 5.9 или новее.

1. Нажмите Command (⌘) + пробел.
2. Напишите «Терминал» или Terminal и нажмите Enter.
3. Скопируйте следующую строку целиком, вставьте её в открытое окно
   и нажмите Enter:

   xcode-select --install

4. Если появилось окно установки Apple, нажмите «Установить» и дождитесь
   завершения. Для загрузки нужен интернет.
5. Если написано, что инструменты уже установлены, переходите к шагу 3.
   Если позже сборка сообщит о слишком старой версии Swift, обновите
   инструменты Apple или Xcode до версии с Swift 5.9 или новее.

ШАГ 3. СОЗДАЙТЕ ПРИЛОЖЕНИЕ И DMG
-------------------------------
1. Вернитесь в папку ClaudeSweep в Finder.
2. Дважды нажмите Package-DMG.command.
3. Откроется Терминал. В нём будут появляться строки на английском.
   Это проверки и сборка программы. Дождитесь окончания, не закрывая окно.
   Этот шаг не запускает очистку ваших данных Claude.
4. При успешном завершении Finder покажет готовый файл в папке dist:

   ClaudeSweep-0.1.0-arm64.dmg — если сборка шла на Apple Silicon;
   ClaudeSweep-0.1.0-x86_64.dmg — если сборка шла для Intel.

   Файл рядом с окончанием .sha256 нужен для проверки целостности.
   Открывать его для установки не требуется.

Если двойной щелчок открывает текст или сообщает о правах доступа:
1. Откройте Терминал, как в шаге 2.
2. Напечатайте слово bash и поставьте после него один пробел.
3. Перетащите файл Package-DMG.command из Finder прямо в окно Терминала.
   Его полный путь подставится автоматически. Не удаляйте кавычки
   и обратные слеши, если они появились.
4. Нажмите Enter и дождитесь окончания.

ШАГ 4. УСТАНОВИТЕ И ОТКРОЙТЕ ПРОГРАММУ
-------------------------------------
1. Дважды нажмите созданный файл с окончанием .dmg.
2. В открывшемся окне перетащите Claude Sweep.app на ярлык Applications
   («Программы»).
3. Дождитесь копирования.
4. Откройте Finder → «Программы» → Claude Sweep.
5. После копирования диск Claude Sweep можно извлечь кнопкой ⏏
   рядом с его названием в боковой панели Finder.

Если нужен только запуск без DMG, в шаге 3 можно открыть Build.command.
После успешной сборки программа будет в папке dist: Claude Sweep.app.
Её можно открыть оттуда или перенести в «Программы».

ЕСЛИ НЕ ПОЛУЧИЛОСЬ
------------------
• Не появилась папка dist или файл DMG:
  вероятно, сборка остановилась с ошибкой. Само закрытие окна Терминала
  не означает успех. Запустите сценарий через bash по инструкции выше,
  чтобы увидеть результат в открытом окне.

• Видите error, failed, Swift compiler или SDK:
  скопируйте последние 30–50 строк из Терминала и отправьте человеку,
  который передал вам архив. По этим строкам можно определить причину.
  Не присылайте пароли, ключи API и содержимое файлов с токенами.

• macOS блокирует запуск или пишет, что разработчик не проверен:
  эта версия не имеет подписи Developer ID и нотариального заверения Apple.
  Не отключайте защиту macOS и не вводите случайные команды из интернета.
  Сохраните точный текст сообщения и передайте автору архива.

• Хотите запустить на другом Mac:
  проще повторить сборку из архива на том Mac. Созданная версия рассчитана
  на архитектуру, указанную в имени DMG, и не является универсальной.

ПЕРВЫЙ ЗАПУСК И ОЧИСТКА
----------------------
Интерфейс программы сейчас на английском.

1. Сохраните нужные данные Claude и закройте Claude, Claude Code
   и редакторы с работающим расширением Claude.
2. Нажмите Scan files («Найти файлы»). Сканирование ничего не удаляет.
3. Просмотрите найденные пути и отметьте только то, что хотите убрать.
   Папки профиля могут содержать историю, настройки, навыки и другие
   нужные данные. Не отмечайте всё автоматически.
4. Нажмите Review cleanup… («Проверить список очистки»).
5. Ещё раз проверьте список. Move to Trash переместит выбранное в Корзину.
   Пока Корзина не очищена, файлы обычно можно восстановить через Finder.

Keychain — раздел сохранённых учётных данных. Их удаление необратимо
и может сделать зашифрованные данные Claude недоступными, включая копии.
Если не уверены, не удаляйте записи из этого раздела.

Browser & settings — подсказки по ручной очистке браузера и настроек.
Activity — результаты выполненных действий.

Программа очищает известные локальные данные. Она не удаляет записи
на серверах Anthropic и не гарантирует отсутствие связи между аккаунтами
или защиту нового аккаунта от блокировки.
